# Nha Minh Frontend

React frontend organized by responsibility:

- `src/assets`: global styles and bundled assets
- `src/components`: reusable UI components
- `src/features`: feature-specific modules
- `src/pages`: application screens
- `src/services`: API clients
- `src/utils`: shared types, constants, and helpers
- `src/context`, `hooks`, `layouts`, `routes`, `store`: extension points for application-wide concerns

Run `npm run dev` for local development, `npm run lint` for TypeScript validation, and `npm run build` for a production build.
